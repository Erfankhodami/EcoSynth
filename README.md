An immersive game that blends ecosystem simulation with synthwave aesthetics.

## About the Project
EcoSynth is a unique game that combines ecological simulation with a vibrant synthwave visual style. Players can interact with a dynamic ecosystem while enjoying retro-futuristic aesthetics and soundscapes.

## Features
- Dynamic ecosystem simulation
- Synthwave-inspired visuals and audio
- Interactive environment
- Evolutionary mechanics
- Beautiful particle effects
